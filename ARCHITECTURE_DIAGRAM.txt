    ↓

    ↓
Database Query Scoped to Tenant
    ↓

    ↓
Rate Limiting Applied
    ↓
Response Returned

KEY TECHNOLOGIES
================

Backend:        FastAPI 0.104, SQLAlchemy 2.0, Python 3.11
Database:       PostgreSQL 14+ (pgvector extension)
LLM/Embedding:  Ollama (self-hosted)
Cache:          Redis 7
Auth:           AWS Cognito (JWT)
Frontend:       React, TailwindCSS, React Query
Containerization: Docker & Docker Compose
Rate Limiting:  slowapi
Document Parsing: pdfplumber, pandas
